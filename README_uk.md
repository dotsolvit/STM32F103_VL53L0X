# Асинхронный драйвер ToF-датчика VL53L0X для STM32F103

[Read me in English](README.md) | **Читати мене Українською**

Оптимізований, легковагий **неблокуючий драйвер на С** для лазерного Time-of-Flight (ToF) датчика відстані **VL53L0X**, розроблений для мікроконтролера STM32F103C8T6 (Blue Pill) на базі бібліотеки **STM32CubeHAL**.

Проєкт є переробленою та архітектурно вдосконаленою версією драйвера *Squieler/VL53L0X---STM32-HAL*. Основний фокус змін спрямований на усунення блокуючих затримок процесора та переведення логіки опитування на асинхронний скінченний автомат.

---

### 🎯 Зроблені покращення та модернізація:
- **Асинхронна архітектура:** Повністю усунуто внутрішні заклинюючі цикли очікування `while()`. Процес заміру розділено на швидкий запуск лазера та незалежне періодичне зчитування прапорця готовності.
- **Корекція порядку байтів (Endianness):** Виправлено помилку інтерпретації двобайтового результату з регістрів даних (`0x1E` та `0x1F`), що забезпечило коректне виведення міліметрів.
- **Розгін заліза (High Speed / Long Range):** Збільшено внутрішні фазові періоди імпульсів лазера та знижено поріг чутливості зворотного сигналу. Це дозволило збільшити дальність приміщення до **~1.9 метрів** при скороченні часу самого вимірювання до **30 мс**.
- **Програмний таймаут:** Додано захисний таймер (`100 мс`), який запобігає зависанню логіки прошивки у разі фізичного відключення або збою ліній датчика під час руху.

---

## 🛠️ Toolchain & Hardware Constraints

- **Target MCU:** STM32F103C8T6 (ARM Cortex-M3 @ 72 MHz)
- **Bus Profile:** Для стабільної роботи асинхронних функцій апаратний модуль I2C в CubeMX необхідно обов'язково налаштувати в режим **Fast Mode (400 000 Hz)**. Швидкість Standard Mode (100 kHz) створює занадто великі затримки під час трансляції пакетів по шині.
- **IDE & Compiler:** STM32CubeIDE (GCC toolchain)

## 🔌 Hardware Connection (Pinout)

| Sensor Pin | STM32F103 Pin | Description |
| :---: | :---: | :--- |
| **VCC** | **3.3V** | Main Power Supply |
| **GND** | **GND** | Common Ground |
| **SCL** | **PB6** | I2C1 Clock (Fast Mode 400 kHz) |
| **SDA** | **PB7** | I2C1 Data (Fast Mode 400 kHz) |
